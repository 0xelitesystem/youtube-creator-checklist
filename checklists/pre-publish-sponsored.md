# Pre-publish checklist: sponsored video

Run this IN ADDITION to the standard pre-publish checklist when the video has a sponsor.

## Disclosure

- [ ] Disclosure spoken at the top of the video, BEFORE any sponsor mention
- [ ] Disclosure visible in description, in the first 120 characters (above the "...more" fold)
- [ ] Disclosure visible on-screen during the sponsored segment
- [ ] YouTube's "Includes paid promotion" toggle is ON (Settings -> Monetization -> Includes paid promotion)
- [ ] Disclosure language is specific ("paid promotion", "sponsored by", not "thanks to")

## Sponsor agreement

- [ ] Talking points / required claims match the contract
- [ ] Required claims are factually accurate (you're personally responsible for false claims, regardless of what the sponsor said)
- [ ] Forbidden topics avoided (most sponsors have things you can't say or compare to)
- [ ] Discount code / coupon / link is correct (not from a different campaign)
- [ ] Tracking link works (test by clicking it)
- [ ] Submission deadline met (if sponsor required preview)

## Sponsor segment quality

- [ ] Segment is clearly delineated from the rest of the video (audio cue, visual cue, or both)
- [ ] Segment doesn't pretend to be organic content
- [ ] Segment length matches the contract
- [ ] Sponsor logo / brand name shown correctly
- [ ] Pronunciation of brand name correct

## After sponsored segment

- [ ] Verbal "and we're back" or similar transition
- [ ] Rest of video is independently produced (not biased to favor sponsor)
- [ ] If reviewing the sponsor's product: independent reviewer would reach similar conclusions, OR you've disclosed the conflict explicitly

## Description

- [ ] Sponsor link with full UTM parameters (if applicable)
- [ ] Sponsor link is the FIRST link in the description (or labeled clearly)
- [ ] Disclosure precedes the sponsor link
- [ ] Discount code prominently shown

## Pinned comment (recommended)

- [ ] Pinned comment with sponsor link + code
- [ ] Pinned comment includes disclosure ("Today's sponsor, paid promotion")

## Legal

- [ ] FTC-compliant disclosure (US): see [affiliate-disclosure-templates](https://github.com/0xelitesystem/affiliate-disclosure-templates)
- [ ] Local jurisdiction equivalents (UK ASA, EU directives, etc.) if applicable

## Communication

- [ ] Sponsor will receive the published URL after going live
- [ ] Performance metrics expected by sponsor are documented
- [ ] Channel for sponsor questions is established
