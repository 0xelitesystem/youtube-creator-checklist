# Pre-publish checklist

Run through this before clicking publish on any video. Aim for 100%; partial completion is how mistakes ship.

## Video file

- [ ] Final cut watched end-to-end at least once after the last edit
- [ ] Audio levels consistent (no segment too loud or too quiet)
- [ ] No leftover placeholder text or color cards
- [ ] No personal info accidentally on screen (notifications, browser tabs, file paths with names)
- [ ] Music/sound effects properly licensed (you own them, you have a license, or they're public domain)
- [ ] Footage from third parties has rights / permission / fair use basis
- [ ] Video matches the title and thumbnail promises (no bait-and-switch)

## Title

- [ ] Title under 100 characters (60 visible on most clients)
- [ ] Title accurately describes the video (no clickbait that the content doesn't deliver)
- [ ] No ALL-CAPS abuse
- [ ] No misleading punctuation (excessive exclamation marks, fake question marks)
- [ ] Searchable keywords included naturally
- [ ] Spell-check passed

## Thumbnail

- [ ] Custom thumbnail uploaded (not auto-generated frame)
- [ ] Readable at small size (test at 200px wide; if you can't read it, viewers can't either)
- [ ] Matches the video's actual content
- [ ] Contrast checks (works in dark mode AND light mode)
- [ ] No personal info accidentally on the thumbnail
- [ ] Doesn't violate platform thumbnail guidelines (no shocking imagery if not warranted)

## Description

- [ ] First 120 characters describe the video accurately (this is what shows in search/sidebar)
- [ ] Disclosure (if affiliate, sponsored, or gifted) is in the first paragraph, not buried
- [ ] All links work (click each one)
- [ ] Affiliate links labeled
- [ ] Sponsorship code/link works (if applicable)
- [ ] Chapter markers in correct format (`0:00 - title` per line, first one starts at 0:00)
- [ ] Hashtags added (3 max, more get ignored, and the first 3 show above the title)

## Chapters / segments

- [ ] First chapter starts at 0:00 (required for YouTube to render chapters)
- [ ] Each chapter is at least 10 seconds
- [ ] Chapter titles are descriptive (not "intro" / "more" / "stuff")
- [ ] Chapter count matches the video structure

## End screens

- [ ] End screens added in last 5-20 seconds
- [ ] Subscribe button positioned in safe area (not over face/critical visuals)
- [ ] Recommended video tile points to a relevant video on your channel
- [ ] Playlist tile (if used) points to the right playlist
- [ ] Test view: do the end screen elements appear when expected?

## Cards

- [ ] Cards added at relevant moments (not the last 20 seconds, that's end-screen territory)
- [ ] Card destinations are correct
- [ ] Cards don't appear during critical demonstrations or text-heavy moments

## Settings

- [ ] Visibility set correctly (Public / Unlisted / Scheduled)
- [ ] If Scheduled: time zone is correct, time is correct
- [ ] Made for kids = NO (unless your channel is genuinely for kids)
- [ ] Age restriction set correctly
- [ ] Comments enabled (and moderation level set per your channel norms)
- [ ] Like count visibility set per your channel norms
- [ ] Notifications setting (notify subscribers ON unless reason not to)

## Category / language

- [ ] Category matches the video content
- [ ] Language set correctly
- [ ] Caption language matches if you uploaded captions

## Captions

- [ ] If you uploaded a caption file: it's the right one for this video
- [ ] If relying on auto-captions: review them later for any embarrassing transcription errors
- [ ] Caption language tag is correct

## Monetization (if applicable)

- [ ] Monetization toggled correctly
- [ ] Self-certification questionnaire answered honestly
- [ ] Paid promotion toggle ON if there's a sponsor (this is in addition to disclosure in description and video)

## Final sanity check

- [ ] Title + thumbnail look like the same video
- [ ] Description first line previews well
- [ ] If you're nervous about anything, fix it before publishing rather than fixing after
