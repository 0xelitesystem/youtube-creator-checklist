# Post-publish checklist (within 2 hours)

Run this within the first 2 hours of publishing.

## Verify the upload

- [ ] Video plays without buffering issues
- [ ] Captions display correctly
- [ ] Chapters render in the progress bar
- [ ] End screens appear at the right time
- [ ] Cards appear at the right times
- [ ] Thumbnail is correct (sometimes the wrong file uploads)
- [ ] Title and description display as intended

## Check links

- [ ] Click every link in the description
- [ ] Click pinned comment links
- [ ] Confirm affiliate / sponsor links go to the right destination
- [ ] Discount codes work (try entering one if applicable)

## Initial engagement

- [ ] Pin a comment (greeting, key resource, or sponsor info)
- [ ] Heart pinned comment
- [ ] Reply to first 5-10 substantive comments
- [ ] Block obvious spam, but don't shadow-mod legitimate criticism

## Cross-promotion

- [ ] Share to platforms where you have an audience (in your normal cadence, don't suddenly spam new channels)
- [ ] Update relevant playlists to include this video
- [ ] If part of a series: link from previous video's description / pinned comment

## Settings double-check

- [ ] Public visibility (or scheduled correctly)
- [ ] Notifications fired (check your subscriber view)
- [ ] Monetization status applied (icon shows green dollar sign)
- [ ] If sponsored: paid promotion banner visible

## Note for retro

- [ ] If you noticed anything mid-edit you wished you'd done differently: write it down. Apply next time.
