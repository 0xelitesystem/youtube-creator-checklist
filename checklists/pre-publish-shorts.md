# Pre-publish checklist: Shorts / vertical video

Run this for vertical short-form video. Many of the long-form items don't apply; new ones do.

## Format

- [ ] Vertical 9:16 aspect ratio
- [ ] Under 60 seconds (or current platform max)
- [ ] Important content in the safe area (avoid edges where UI overlays appear)

## Hook

- [ ] First 3 seconds have visible movement (not a static talking head)
- [ ] First frame shows what the video is about (not a logo card or "hey what's up")
- [ ] Hook delivers what the rest of the video promises

## Captions

- [ ] On-screen captions for the entire video (most viewers watch muted)
- [ ] Captions are large and high-contrast
- [ ] Captions don't overlap with platform UI

## Audio

- [ ] If using popular audio: you have rights (platform-licensed library, original, or licensed cover)
- [ ] Audio doesn't overpower voiceover
- [ ] Voice is intelligible without captions if possible (some viewers do listen)

## Title and description

- [ ] Title is short, specific (Shorts titles get truncated heavily)
- [ ] Description includes any disclosure (still required even on Shorts)
- [ ] Hashtags relevant (3-5 max)
- [ ] No misleading hashtags (#viral on a video that isn't, etc.)

## Disclosure

- [ ] If affiliate / sponsored / gifted: disclosed verbally in first 3 seconds AND on-screen
- [ ] YouTube's "Includes paid promotion" toggle ON if applicable

## Loop check

- [ ] Does the end of the Short make sense if it loops back to the start?
- [ ] If loop is intentional: the cut is clean
- [ ] If loop isn't intentional: there's a clear ending cue (e.g. "thanks for watching")

## Settings

- [ ] Made for kids = NO (unless genuinely for kids)
- [ ] Public / Unlisted / Scheduled set correctly
- [ ] Allow embedding ON
- [ ] Comments enabled (or disabled per channel norms)
