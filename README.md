# youtube-creator-checklist

Pre-publish, post-publish, and monthly review checklists for YouTube creators. Useful as a final pass before hitting publish, and as a recurring quality discipline.

## Why this exists

Most "creator workflow" content online is course bait. This is a checklist. Print it, save it as a doc, copy it into Notion. Run through it. Ship better videos.

## How to use

1. Open the relevant checklist
2. Copy it into your project tool of choice (Notion / Trello / sticky notes / paper)
3. Run through every box before the moment in your workflow it's intended for
4. Customize: delete items that don't apply to your channel, add items specific to your niche

## What's NOT in these checklists

- **Strategy advice.** When to post, what topics to cover, what thumbnails work, those are channel-specific and not amenable to a checklist.
- **Algorithm hacks.** None of these will help you "beat the algorithm." Quality fundamentals are the goal.
- **Promotional tactics.** No "comment for engagement" or "ask viewers to subscribe 5 times per video."
- **Specific tool recommendations.** The checklists are tool-agnostic. Use whatever editor / thumbnail tool / analytics tool you prefer.

## What you'll catch

Working through the pre-publish checklist regularly catches:

- Missing or wrong disclosure
- Broken links in description
- Wrong thumbnail uploaded
- Forgotten chapter markers
- End screens off-positioned
- Cards pointing to the wrong video
- Title typos
- Wrong category / language / subtitle settings

The post-publish and review checklists catch:

- Comments that need responses or moderation
- Initial-hour metric anomalies (drops, spikes, traffic source surprises)
- Patterns over time (which formats work, which don't, retention trends)
